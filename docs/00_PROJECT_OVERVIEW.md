# AI 수면시간 분석 서비스 - 프로젝트 개요

## 프로젝트명
Sleep Insight AI

## 프로젝트 목적
사용자가 자신의 수면 상태 및 생활 패턴을 입력하면,
AI가 긍정 / 부정 / 중립 상태를 분석하여 결과를 제공하는 웹 서비스 구축.

---

# 핵심 기능
- 텍스트 입력
- AI 수면 분석
- 긍정/부정/중립 결과 제공
- 신뢰도 표시
- 분석 이유 제공
- 분석 결과 저장
